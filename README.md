# CVBarcode

**CVBarcode** — это валидатор штрих-кодов стандарта **EAN-13**. Программа проверяет подлинность введённого кода, сверяя префикс страны-производителя с базой GS1 и вычисляя контрольную цифру по алгоритму Modulo 10.

Проект разработан в рамках краевой работы по информатике.

## 📌 О программе
Программа принимает на вход 13-значный код (имитация сканирования), после чего проводит две проверки:
1.  **Префикс страны:** Первые три цифры кода сверяются с международным реестром префиксов, чтобы определить, существует ли такая страна-производитель.
2.  **Контрольная цифра:** С помощью математического алгоритма вычисляется последняя цифра кода. Если она совпадает с введённой, значит, код не содержит опечаток и является валидным.

В программе реализована защита от некорректного ввода: она не пропустит буквы вместо цифр или код неправильной длины.

## 💻 Почему два языка?
Проект реализован на двух языках программирования намеренно, чтобы показать разницу в подходах и продемонстрировать разные навыки.

### 🐍 Python (Папка `python`)
**Почему:** Python выбран как язык для быстрой разработки логики и наглядного представления алгоритма.
**Как реализовано:** Весь код разбит на модули (отдельно логика проверки, отдельно запуск). Программа показывает, как легко и лаконично можно реализовать сложные вычисления (например, разворот строки и работу с индексами) без лишнего синтаксического шума. Также в папке есть версия, скомпилированная в `.exe` через PyInstaller.

### ⚙️ C++ (Папка `C++`)
**Почему:** C++ выбран для получения нативного, быстрого и независимого исполняемого файла (`.exe`), который работает без установленного интерпретатора Python.
**Как реализовано:** Код написан с использованием стандартной библиотеки (`std::string`, `std::vector`). В отличие от Python, здесь требуется строгая типизация и ручное управление памятью, что даёт понимание того, как программа взаимодействует с "железом" на низком уровне. Итоговый файл весит в разы меньше аналога на Python и запускается мгновенно.

## 🚀 Как запустить

### Способ 1. Запуск готовых файлов (Windows)
В разделе **[Releases](https://github.com/kolokocka/CVBarcode/releases)** скачайте готовые файлы:
*   `CVBarcode_on_cpp.exe` — нативная версия на C++ (рекомендуется).
*   `CVBarcode_on_py.exe` — версия на Python, упакованная в exe.
Просто запустите нужный файл и следуйте инструкциям в консоли.

### Способ 2. Запуск из исходников
**Для Python:**
1. Перейдите в папку `python`.
2. Запустите скрипт: `python main.py`

**Для C++:**
1. Перейдите в папку `C++`.
2. Скомпилируйте исходный код (например, через `g++`) или запустите уже готовый `.exe`.

## 🛠️ Используемые технологии
*   **Python 3** (модульная структура, списки, срезы)
*   **C++** (стандартная библиотека, компиляция в бинарник)
*   **PyInstaller** (сборка Python-версии в exe)
*   **Git / GitHub** (контроль версий)
